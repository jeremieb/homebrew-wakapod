# Wakapod Terminal for Homebrew

The Homebrew tap for a terminal client for [Wakapod](https://wakapod.app).

<img width="1427" height="1146" alt="terminal" src="https://github.com/user-attachments/assets/a6175df8-2905-4860-9534-4869d04b3084" />

## Install

On macOS, install Wakapod Terminal with [Homebrew](https://brew.sh/):

```sh
brew install jeremieb/wakapod/wakapod
```

Then launch it with:

```sh
wakapod
```

## Update

```sh
brew update
brew upgrade wakapod
```

## Uninstall

```sh
brew uninstall wakapod
```

## Optional: Opus playback

Install `mpv` if you need the optional Opus playback fallback:

```sh
brew install mpv
```

## Documentation

See the [Wakapod Terminal documentation](https://doc.wakapod.app/terminal/) for setup and usage.
